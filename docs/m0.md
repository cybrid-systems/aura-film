# M0 — 24-hour invention clock

Dogfood film: human invention history compressed into one day. Soft owns
the map. The blit only paints `SNAP`.

## Law

```
now          = 2026          end of the day, displayed 00:00:00.000
span         = 3,240,000 years = 86,400,000 ms
ms_before    = years_ago * 80 / 3          integer division
clock_ms     = 0 if ms_before >= day else day - ms_before
```

`80/3` ms per year is exactly 20 minutes per 45,000 years, so cave art at
year `2026 - 45000 = -42974` is `23:40:00.000`. Paper (105), rail (1825),
and the personal computer (1977) are the same function. They are not a
second table of clock strings. The article's published subseconds
(`23:59:09`, `23:59:54.7`, `23:59:58.71`) are rounded; M0 prints the
integer law:

| id | year | clock | scene | tone Hz |
|----|------|-------|-------|---------|
| origin | -3237974 | 00:00:00.000 (start, progress 0) | wild | 0 |
| cave | -42974 | 23:40:00.000 | hand | 196 |
| paper | 105 | 23:59:08.774 | paper | 262 |
| rail | 1825 | 23:59:54.640 | rail | 330 |
| pc | 1977 | 23:59:58.694 | terminal | 440 |
| here | 2026 | 00:00:00.000 (end, progress 1000000, AT_NOW) | sphere | 523 |

Caption on `here` is `YOU ARE HERE`. The Chinese line from the Fable
write-up ("你在这里") is the same beat; the SNAP caption stays ASCII so
the M0 blit does not need a CJK font file.

Wilderness between named beats holds the previous scene (`cut=dense`,
`reason=hold_scene`). An exact beat selects `cut=austere`,
`reason=on_beat`. Both scores run on the caller. The stamp is
`WORLD line=host-sequential`. M0 does not print a fiber-live stamp.

Tone `0` is silence. Later tones are music parameters, not a recording.
